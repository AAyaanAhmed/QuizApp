# CLI Quiz Application

## Overview

This project is a command-line quiz application developed using Python. It loads quiz questions from a JSON file, displays one question at a time, accepts user answers, calculates the final score, and shows the overall result.

## Features

Loads questions from a JSON file.

Displays multiple-choice questions.

Checks user answers.

Calculates score and percentage.

Shows a final performance grade.

Handles missing or invalid JSON files.

## Technologies

Python

JSON

## Project Files

quiz.py

questions.json

## How to Run

Download or clone the project.

Open the project folder in a terminal.

Run the program.

python quiz.py

Answer each question by entering A, B, C, or D.

View the final score and result after completing the quiz.
